# MBA Business Analytics Portfolio

Coursework and project work from my MBA (Business Analytics specialization), 2019–2020. Originally scattered across several uncategorized repositories with no documentation; consolidated here by technique, with each project's original code left unmodified.

## Contents

| Folder | Technique | Summary |
|---|---|---|
| [01-predictive-modeling](01-predictive-modeling/) | Random Forest, SVM, Neural Networks (R) | Three classification/prediction exercises: credit risk, letter recognition, concrete strength |
| [02-nlp-text-mining](02-nlp-text-mining/) | Extractive text summarization (Python/NLTK) | Sentence-similarity-based automatic summarization |
| [03-data-visualization](03-data-visualization/) | EDA & visualization (Python) | Exploratory analysis of the IBM HR Analytics attrition dataset |
| [04-bi-dashboarding](04-bi-dashboarding/) | BI dashboarding (IBM Cognos) | Global suicide rates (1985–2016) dashboard and report |
| [05-capstone-demand-forecasting-system](05-capstone-demand-forecasting-system/) | Time-series forecasting (ARIMA), market basket analysis (Apriori), Flask | Trimester 5 capstone — a deployed demand-forecasting web application |
| [06-placements-analysis](06-placements-analysis/) | Data aggregation, Flask | Group project analyzing MBA placement outcomes by specialization |
| [07-unisys-hr-analytics-internship](07-unisys-hr-analytics-internship/) | Data consolidation (Python), Tableau dashboarding | Internship project: talent heat-map and manager-assessment dashboards for Unisys HR — where I first learned Python |

## Timeline

Earliest work Aug 2019 (data visualization) through the capstone in early 2020, spanning the core analytics toolkit taught across the program: predictive modeling, time-series forecasting, association rule mining, NLP, and BI dashboarding. The Unisys internship (mid-2019) sits alongside this timeline and is where the Python skills used in the later capstone were first picked up.

This repo consolidates seven previously separate repositories (`Predictive_noob`, `TEXT`, `Viz`, `NON_CODES`, and the `DEMAND_FRCST`/`PLACEMENTS` folders of `COLLEGE_PROJECTS`) into one organized structure. Two additional repos (`lecture0`, `trial`) contained no substantive content and were retired rather than migrated. Original file contents are unchanged — only location and documentation were added.
