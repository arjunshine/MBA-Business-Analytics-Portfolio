# MBA Business Analytics Portfolio

Coursework and project work from my MBA (Business Analytics specialization), 2019–2020. Originally scattered across several uncategorized repositories with no documentation; consolidated here by technique, with each project's original code left unmodified.

## Contents

| Folder | Technique | Summary |
|---|---|---|
| [01-predictive-modeling](01-predictive-modeling/) | Random Forest, SVM, Neural Networks (R) | Predicting outcomes before they happen: credit default risk (lending decisions), character recognition, and concrete compressive strength (quality control) — the yes/no and threshold calls a business needs to make in advance, not after |
| [02-nlp-text-mining](02-nlp-text-mining/) | Extractive text summarization (Python/NLTK) | Cuts a document down to its most representative sentences automatically — saves someone from reading the full thing for the gist, without the risk of inventing content that was never there (extractive, not generative) |
| [03-data-visualization](03-data-visualization/) | EDA & visualization (Python) | Surfaces which factors actually correlate with employee attrition — the analysis a retention-focused HR team runs before deciding where to intervene |
| [04-bi-dashboarding](04-bi-dashboarding/) | BI dashboarding (IBM Cognos) | Makes a public-health trend legible at a glance to a non-technical audience — the same curated-framing discipline BI dashboarding for any executive stakeholder requires |
| [05-capstone-demand-forecasting-system](05-capstone-demand-forecasting-system/) | Time-series forecasting (ARIMA), market basket analysis (Apriori), Flask | Deployed, not just modeled: lets a food-service business forecast demand per menu item and see what's commonly ordered together, so inventory decisions get made ahead of demand instead of in reaction to it. Graded A+, part of an overall First Class with Distinction result |
| [06-placements-analysis](06-placements-analysis/) | Data aggregation, Flask | Replaced a placement committee's manual, per-recruiter spreadsheet cross-referencing with a repeatable upload-and-match tool — run against real company drives, not a classroom exercise. Built solo while serving as the university's own Student Placement Coordinator, automating my own job |
| [07-unisys-hr-analytics-internship](07-unisys-hr-analytics-internship/) | Data consolidation (Python), Tableau dashboarding | Gave Unisys HR a repeatable, filterable tool for where to focus hiring, replacing one-off manual searches, plus a manager-assessment dashboard for team-level HR health — and the project that forced me to learn Python in the first place, out of necessity rather than a course requirement |

## Timeline

Earliest work Aug 2019 (data visualization) through the capstone in early 2020, spanning the core analytics toolkit taught across the program: predictive modeling, time-series forecasting, association rule mining, NLP, and BI dashboarding. The Unisys internship (mid-2019) sits alongside this timeline and is where the Python skills used in the later capstone were first picked up.
