# Predictive Modeling (R)

Three foundational classification/prediction exercises, October 2019.

- **`RF_Classification[German_cred].Rmd`** — Random Forest classification on the German Credit dataset (credit risk prediction).
- **`SVM_LetterRecog.Rmd`** — Support Vector Machine classifying handwritten letter images (26 classes) using the UCI letter recognition dataset. Notes the importance of feature normalization for SVM.
- **`neural_network.Rmd`** — Neural network predicting concrete compressive strength from mix composition.

Open the `.Rmd` files in RStudio (or any Markdown-aware R environment) to run them; they render to HTML with inline code and output.
